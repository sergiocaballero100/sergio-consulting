# Sergio Consulting

Primera version de la pagina personal de Sergio Caballero, consultor funcional de Dynamics 365 Finance & Operations.

## Ejecutar localmente

La pagina es estatica y no requiere Node.js para abrirse. Abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estatico.

## Publicar en Vercel

1. Importa este repositorio desde GitHub en Vercel.
2. Usa la raiz del proyecto como directorio.
3. No necesitas comando de build; deja el output como raiz.

Tambien puedes desplegar la carpeta con Vercel CLI cuando este instalada.

## Antes de publicar

Reemplaza el `mailto:` vacio de `index.html` por tu correo profesional real. El CV compartido no incluye una direccion de contacto.

## Contenido

El contenido se basa en el CV de agosto de 2026: mas de 15 anos en consultoria ERP, Dynamics AX 2012 y D365 F&O, operaciones en mas de 25 paises, soporte L1-L3, SCM, inventarios, master planning, P2P, O2C, diseno funcional y liderazgo de proyectos.
